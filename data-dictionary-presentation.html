เอกสารประกอบการออกแบบระบบ

พจนานุกรมข้อมูล (Data Dictionary)

ระบบจัดการเรียนการสอนและการเรียนรู้แบบเกมมิฟิเคชัน (Modern LMS & Gamification System)

ฐานข้อมูล: PostgreSQL (Prisma ORM)

จำนวนตารางทั้งหมด: 11 ตาราง

มาตรฐานคีย์หลัก: UUID v4 (Security-focused)

ขอบเขตสิทธิ์ผู้ใช้งาน: RBAC (Role-based)

สารบัญตารางฐานข้อมูล (Database Catalog)

ตารางทั้งหมด 11 ตาราง แบ่งกลุ่มตามสถาปัตยกรรมโมดูลการใช้งาน

ชื่อตาราง (Table Name) ประเภทตาราง (Type) คีย์หลัก (PK) คำอธิบายหน้าที่ในระบบ (Description)
users Master Table id (UUID) เก็บข้อมูลบัญชีผู้ใช้งาน สิทธิ์ผู้ใช้ (ครู, นักเรียน, แอดมิน) และข้อมูลโปรไฟล์
classrooms Master Table id (UUID) เก็บข้อมูลวิชาเรียนและห้องเรียนหลักที่ครูสร้างขึ้นรายปีการศึกษา
student_classes Junction Table id (UUID) บันทึกคู่การลงทะเบียนของนักเรียนและห้องเรียนวิชาที่เรียนจริง
assignments Transaction Table id (UUID) เก็บข้อมูลการสั่งงานการบ้านและลิงก์ข้อสอบ Google Forms ของแต่ละคลาส
submissions Transaction Table id (UUID) บันทึกประวัติการส่งการบ้าน คะแนนที่ได้ และฟีดแบคจากครู
attendance Transaction Table id (UUID) เก็บสถิติประวัติการเช็คชื่อเข้าชั้นเรียนประจำวัน (มา, ขาด, สาย, ลา)
course_materials Transaction Table id (UUID) เก็บข้อมูลสไลด์ วิดีโอ หรือลิงก์สื่อการสอนที่ครูแชร์ในคลาสเรียน
game_scores Log Table id (UUID) เก็บบันทึกประวัติคะแนนดิบรายรอบการเล่นมินิเกมของนักเรียน
leaderboards Cache Table id (UUID) ตารางแคชสะสมผลคะแนนรวมสุทธิและลำดับอันดับของเด็กภายในห้องเรียน
notifications Transaction Table id (UUID) เก็บรายการข้อมูลข้อความการแจ้งเตือนความเคลื่อนไหวรายบุคคล
academic_year_logs Log Table id (UUID) เก็บประวัติปิดเทอมเลื่อนระดับชั้นเรียน (Rollover) และสำรอง JSON Snapshot

ตาราง users (ข้อมูลบัญชีผู้ใช้งาน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสประจำตัวบัญชีผู้ใช้งานที่ระบบสุ่มสร้างขึ้นผ่าน UUID v4 เพื่อความปลอดภัย
role Role (Enum) Default: STUDENT สิทธิ์ผู้ใช้งานในระบบ: STUDENT | TEACHER | ADMIN
name VarChar(255) REQUIRED ชื่อจริง - นามสกุลจริงของผู้ใช้
password VarChar(255) REQUIRED รหัสผ่านสำหรับล็อกอินเข้าระบบที่ผ่านการเข้ารหัสความปลอดภัย (Hashed) ด้วย bcryptjs
status StudentStatus (Enum) Default: ACTIVE สถานะการเรียนของนักเรียน: ACTIVE | GRADUATED | RETAINED | TRANSFERRED
avatar_url VarChar(255) NULLABLE รหัสรูปประจำตัวอวาตาร์ Preset ของระบบ (preset-1 ถึง preset-6) บล็อกรูปภายนอก
password_hint VarChar(255) NULLABLE คำช่วยจำรหัสผ่าน / รหัสผ่านดั้งเดิมที่ครูแอดมินสร้างไว้ให้กรณีจัดสอบครั้งแรก
student_id VarChar(50) UNIQUE, NULLABLE รหัสประจำตัวนักเรียน (เฉพาะเด็กนักเรียน) ห้ามลงซ้ำกับคนอื่น
nickname VarChar(50) NULLABLE ชื่อเล่นของนักเรียน
gender VarChar(10) NULLABLE เพศวิถีของผู้เรียน (ชาย / หญิง)
roll_number VarChar(50) NULLABLE เลขที่ห้องเรียนของนักเรียน
parent_phone VarChar(50) NULLABLE เบอร์โทรศัพท์ติดต่อของผู้ปกครองนักเรียน
created_at DateTime Default: now() วันเวลาที่บันทึกเพิ่มบัญชีผู้ใช้งาน

ตาราง classrooms (ข้อมูลวิชาห้องเรียน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักประจำกลุ่มรายวิชาห้องเรียน
name VarChar(255) REQUIRED ชื่อวิชาเรียนวิชาคอมพิวเตอร์ที่จัดตั้งขึ้น (เช่น วิทยาการคำนวณ)
year_level VarChar(50) REQUIRED ระดับชั้นเรียนของคลาสเรียน (เช่น ม.1, ม.2, ม.3)
room VarChar(50) REQUIRED หมายเลขห้องเรียนย่อย (เช่น 1, 2)
academic_year VarChar(4) REQUIRED ปีการศึกษาที่ดำเนินการเรียนการสอน (เช่น 2568)
teacher_id String (UUID) FOREIGN KEY (Restrict) รหัสคุณครูผู้ดูแลห้องเรียนวิชา เชื่อมโยง users.id [ห้ามลบครูถ้าห้องยังมีอยู่]
created_at DateTime Default: now() วันและเวลาที่ลงบันทึกสร้างห้องเรียนวิชา

ตาราง student_classes (ข้อมูลการลงทะเบียนเรียน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสการจับคู่ลงทะเบียนรายบุคคล
student_id String (UUID) FOREIGN KEY (Cascade) รหัสนักเรียนผู้สมัครเรียน เชื่อมโยง users.id [ลบอัตโนมัติตามนักเรียน]
class_id String (UUID) FOREIGN KEY (Cascade) รหัสห้องเรียนคลาสที่เรียน เชื่อมโยง classrooms.id [ลบอัตโนมัติตามห้องเรียน]
joined_at DateTime Default: now() วันเวลาที่ลงทะเบียนเข้าร่วมคลาสเรียน
student_id + class_id Compound Key UNIQUE CONSTRAINT จำกัดกฎห้ามนักเรียนคนเดิมลงทะเบียนวิชาห้องเดิมซ้ำซ้อนกันในฐานข้อมูล

ตาราง assignments (ข้อมูลงานที่มอบหมาย)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักของการบ้านหรืองานมอบหมายแต่ละชิ้น
class_id String (UUID) FOREIGN KEY (Cascade) รหัสห้องเรียนต้นสังกัดที่งานนี้ถูกสร้างขึ้น เชื่อมโยง classrooms.id [ลบตามห้อง]
title VarChar(255) REQUIRED หัวข้อวิชาการสั่งการบ้านหรือหัวเรื่องทำแบบทดสอบ
description Text NULLABLE รายละเอียด คำสั่ง หรือคำอธิบายภารกิจที่มอบหมายเพิ่มเติม
max_points Int Default: 10 จำนวนคะแนนเต็มทั้งหมดของงานชิ้นนั้นๆ
is_google_form Boolean Default: false ระบุว่างานชิ้นนี้สั่งสอบผ่านการฝังข้อสอบออนไลน์ Google Forms หรือไม่
google_form_url VarChar(500) NULLABLE ลิงก์ปลายทางแบบฟอร์ม Google Forms สำหรับใช้ดึงรันใน Iframe ฝั่งของเด็กนักเรียน
due_date DateTime NULLABLE วันและเวลากำหนดส่งงานสูงสุด หากเกินนี้ระบบจะมาร์กเป็นส่งสาย
status AssignmentStatus Default: DRAFT สถานะการ์ดการบ้าน: DRAFT (ฉบับร่าง) | PUBLISHED (เผยแพร่) | CLOSED (ปิดรับงาน)

ตาราง submissions (ข้อมูลประวัติการส่งการบ้าน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสประวัติการส่งการบ้านเป็นรอบรายบุคคล
student_id String (UUID) FOREIGN KEY (Cascade) รหัสนักเรียนผู้ส่งคำตอบ เชื่อมโยง users.id [ลบตามตัวผู้เรียน]
assignment_id String (UUID) FOREIGN KEY (Cascade) รหัสของการบ้านที่นักเรียนต้องการส่งงาน เชื่อมโยง assignments.id [ลบตามงาน]
file_url VarChar(500) NULLABLE ลิงก์ที่อยู่จัดเก็บไฟล์เอกสารการบ้านบนระบบ [เว้นว่างได้เมื่อทำข้อสอบออนไลน์]
score Int NULLABLE คะแนนดิบประเมินผลจริงที่ได้บันทึกตรวจการบ้านแล้ว
feedback Text NULLABLE คำวิจารณ์ แนะนำ หรือฟีดแบคจากคุณครูผู้ประเมิน
status SubmissionStatus Default: SUBMITTED ขั้นตอนการตรวจงาน: SUBMITTED | LATE (ส่งช้ากว่ากำหนด) | GRADED (ตรวจแล้ว)
student_id + assignment_id Compound Key UNIQUE CONSTRAINT บังคับกติกาห้ามนักเรียนคนเดิมส่งคำตอบการบ้านชิ้นเดิมซ้ำหลายรอบ

ตาราง attendance (ข้อมูลการเช็คชื่อเข้าเรียน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักประจำรายการประวัติเช็คชื่อ
student_id String (UUID) FOREIGN KEY (Cascade) รหัสนักเรียนผู้ได้รับการเช็คชื่อเข้าเรียน เชื่อมโยง users.id [ลบตามตัวผู้เรียน]
class_id String (UUID) FOREIGN KEY (Cascade) รหัสกลุ่มห้องเรียนวิชาที่บันทึกเวลาเรียน เชื่อมโยง classrooms.id [ลบตามคลาส]
date Date REQUIRED วันที่เช็คชื่อ (จัดเก็บเฉพาะ วัน-เดือน-ปี ไม่เก็บเวลา)
status AttendanceStatus Default: PRESENT สถานะเข้าเรียน: PRESENT (มา) | ABSENT (ขาด) | LATE (สาย) | LEAVE (ลา)
note Text NULLABLE คำบันทึกช่วยจำเพิ่มเติม (เช่น ไปแข่งกีฬาโรงเรียน, ส่วยไม่สบายขอลา)
student_id + class_id + date Compound Key UNIQUE CONSTRAINT บล็อกระบบไม่ให้คุณครูเช็คชื่อนักเรียนคนเดิมซ้ำสองรอบในวันเดียวกัน

ตาราง course_materials (ข้อมูลสื่อบทเรียน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสประจำรายการสื่อประกอบการสอนเอกสาร
class_id String (UUID) FOREIGN KEY (Cascade) รหัสวิชาห้องเรียนที่ได้รับข้อมูลแชร์สื่อสอน เชื่อมโยง classrooms.id [ลบตามคลาส]
title VarChar(255) REQUIRED หัวข้อเรื่องหรือหัวประเด็นสไลด์บทเรียนวิชาที่เผยแพร่
type MaterialType (Enum) Default: FILE ประเภทโครงสร้างของข้อมูลสื่อ: SLIDE | VIDEO | LINK | FILE
file_url VarChar(500) REQUIRED ลิงก์ URL ปลายทางสำหรับเปิดดูไฟล์ หรือลิงก์สำหรับดาวน์โหลดสไลด์
is_locked Boolean Default: false เช็คว่าสื่อชิ้นนี้ถูกครูสั่งปิดซ่อนบทเรียนห้ามนักเรียนดูอยู่หรือไม่
unlocks_at DateTime NULLABLE กำหนดวันเวลาปลดล็อกประมวลผลการเข้าดูสื่อศึกษาอัตโนมัติล่วงหน้า

ตาราง game_scores (ข้อมูลคะแนนดิบมินิเกม)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักประจำตาการเล่นกิจกรรมมินิเกม
student_id String (UUID) FOREIGN KEY (Cascade) รหัสนักเรียนผู้ดำเนินเล่นกิจกรรมเกม เชื่อมโยง users.id [ลบตามตัวนักเรียน]
game_type VarChar(100) REQUIRED ชื่อเกมย่อยที่เด็กเล่นทำคะแนน เช่น typing-diner, bug-hunter
session_id VarChar(100) NULLABLE รหัสรอบเฉพาะของเกมย่อย เพื่อตรวจสอบระบบกันส่งคะแนนซ้ำ
points Int REQUIRED ยอดแต้มคะแนนสะสมดิบที่ทำได้ในตาการเล่นรอบนั้น
metadata Json NULLABLE จัดเก็บสถิติทางเทคนิคเสริมแบบความเร็วพิมพ์หรือความผิดพลาดในไฟล์ JSON
created_at DateTime Default: now() วันเวลาส่งบันทึกคะแนนรอบเล่นเกมเข้าระบบ

ตาราง leaderboards (ข้อมูลแคชลีดเดอร์บอร์ด)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสอ้างอิงแคชรวมคะแนนสะสม
student_id String (UUID) FOREIGN KEY (Cascade) รหัสนักเรียนสะสมคะแนนวิชา เชื่อมโยง users.id [ลบตามนักเรียน]
class_id String (UUID) FOREIGN KEY (Cascade) รหัสวิชาห้องเรียนคลาสที่ทำการประเมินอันดับ เชื่อมโยง classrooms.id [ลบตามห้อง]
total_points Int Default: 0 จำนวนผลรวมแต้มคะแนนสะสมสุทธิสำหรับการขึ้นแสดงกระดานเกียรติยศ
rank Int NULLABLE อันดับที่คำนวณเรียงจากมากไปน้อยของผู้เรียนในวิชานั้น (1, 2, 3...)
last_synced DateTime Default: now() วันเวลาล่าสุดที่ทำการสั่งบวกซิงค์คะแนนสุทธิ
student_id + class_id Compound Key UNIQUE CONSTRAINT จำกัดกฎไม่ให้นักเรียนหนึ่งคนมีคอลัมน์แคชลีดเดอร์บอร์ดซ้ำซ้อนในห้องเรียนเดียวกัน

ตาราง notifications (ข้อมูลแจ้งเตือนข่าวสาร)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักของการจัดส่งการแจ้งเตือนเดี่ยว
recipient_id String (UUID) FOREIGN KEY (Cascade) รหัสบัญชีผู้ใช้งานที่ได้รับการแจ้งข่าวสาร เชื่อมโยง users.id [ลบตามตัวผู้รับ]
type NotificationType (Enum) Default: INFO ประเภทความสําคัญ: INFO (ข้อมูล) | WARNING (เตือน) | SUCCESS (สำเร็จ) | ALERT (ด่วน)
title / message VarChar(255) / Text REQUIRED หัวเรื่องข้อมูลแจงอย่างย่อ และข้อความอธิบายข้อมูลการแจ้งเตือนละเอียด
related_type / related_id VarChar / UUID NULLABLE ตารางต้นสังกัดเหตุการณ์แนะไอดีอ้างอิง สำหรับใช้ในการกดดูเชื่อมต่อหน้าระบบ
is_read Boolean Default: false สลับประวัติใช้ระบุว่า ผู้เรียนได้เปิดคลิกอ่านแจ้งเตือนข่าวชิ้นนั้นๆ แล้วหรือไม่
created_at DateTime Default: now() วันและเวลาที่ระบบสั่งยิงข้อมูลการแจ้งข้อความเข้าระบบ

ตาราง academic_year_logs (ข้อมูลบันทึกประวัติปิดปีเรียน)

ชื่อฟิลด์ (Field Name) ประเภทข้อมูล (Data Type) ข้อจำกัด (Constraints) คำอธิบายหน้าที่การจัดเก็บ (Description)
id String (UUID) PRIMARY KEY รหัสหลักประจำรายการล็อกประวัติการปิดรอบปิดปีศึกษา
executed_by String (UUID) FOREIGN KEY (Cascade) คุณครู/ผู้ดูแลระบบผู้รันกระบวนการปิดปีศึกษา เชื่อมโยง users.id
from_year / to_year VarChar(4) REQUIRED ปีการศึกษาก่อนเลื่อนระดับชั้น และปีการศึกษาถัดไปใหม่หลังเลื่อนระดับ
retained_count / graduated_count Int REQUIRED สถิติจำนวนรวมของนักเรียนเรียนซ้ำชั้นเดิม และนักเรียน ม.3 สำเร็จจบการศึกษา (คน)
promoted_count Int REQUIRED สถิติจำนวนรวมนักเรียน ม.1, ม.2 ที่ได้รับการประเมินเลื่อนขึ้นชั้นสำเร็จ (คน)
executed_at DateTime Default: now() วันและเวลาที่ตัวเซิร์ฟเวอร์รันการเลื่อนชั้นเรียนสำเร็จเรียบร้อย
backup_json Json NULLABLE ตัวสำรองเก็บ Snapshot โครงสร้างนักเรียนและห้องวิชาเก่า เพื่อรันเรียกคืน (Rollback)

กฎความถูกต้องฐานข้อมูล (Constraints & Rules)

1. มาตรฐานการระบุตัวตน (Entity Identity)

ตารางข้อมูลทั้งหมดใช้ชนิดข้อมูลสุ่ม UUID v4 เพื่อป้องกันความเสี่ยงด้านความปลอดภัยจากการดักจับ (ID Enumeration Vulnerability) เพื่อความเป็นส่วนตัวและความมั่นคงสูงสุดของระบบ

2. การลบข้อมูลเกี่ยวโยง (Referential Actions)

  • ON DELETE CASCADE (ลบตาม): ใช้กับข้อมูลประวัติย่อย เช่น submissions, attendance, course_materials เพื่อล้างขยะข้อมูลเมื่อลบตารางหลัก
  • ON DELETE RESTRICT (ห้ามลบ): ใช้กับความสัมพันธ์ของ classrooms และ users เพื่อจำกัดไม่ให้ลบบัญชีครูผู้สอนหากวิชานั้นยังรันระบบสอนอยู่

3. กฎความสมบูรณ์จำเพาะ (Compound Unique Indexes)

คุมความถูกต้องของข้อมูลเชิงตรรกะธุรกิจ เช่น จำกัดการลงชื่อเข้าห้องซ้ำซ้อนใน student_classes (studentId + classId) และการเช็คชื่อเข้าชั้นเรียนประจำวัน (studentId + classId + date)
